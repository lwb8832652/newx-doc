新增 HRM 人力资源管理系统、FMS 财务管理系统，支持独立手机端操作 ​

本月概要：

  • 【HRM】完成人力资源管理模块整合，补齐对应的后端工程与业务能力，并支持 Admin 移动端。
  • 【FMS】完成财务管理模块整合，补齐对应的后端工程与业务能力，并支持 Admin 移动端。

🐞 问题修复 ​

后端框架专区：

  • 【修复】修复阿里云 OSS、七牛云使用自定义域名时前端直传签名地址生成错误的问题，签名节点改用服务商 endpoint，并补充对应单元测试，由 @situjunjie 贡献 !1588 ，对应 https://t.zsxq.com/qYxXZ
  • 【修复】邮件模板 HTML 代码块内容包含 $ 或反斜杠时，MailTemplateServiceImpl 使用正则替换可能抛出 IllegalArgumentException 的问题，通过 Matcher.quoteReplacement 安全处理替换内容，由 @nemisolv 贡献 #1204
  • 【修复】WebProperties 嵌套配置属性未正确进行级联校验的问题，为 appApi、adminApi、adminUi 增加 @Valid 校验，由 @nemisolv 贡献 #1187
  • 【修复】单体版、微服务版 GlobalExceptionHandler 处理携带成功码（code = 0）的 ServiceException 时，避免继续调用 CommonResult.error 抛出异常，统一返回系统异常，由 @芋道源码 修复 单体版 d7411081 、微服务版 4658bca2 ，对应 #1196
  • 【修复】单体版、微服务版在多 SecurityFilterChain 场景下，TokenAuthenticationFilter 被 Spring Boot 注册为 Servlet 全局过滤器，导致独立安全链请求被越界处理的问题；通过禁用 FilterRegistrationBean 自动注册，确保过滤器仅由 Spring Security FilterChain 管理，由 @芋道源码 修复 单体版 809d6aaa 、微服务版 1731933a ，对应 #1198
  • 【修复】修复 BPM 流程发起人部门负责人获取错误的问题，优先使用流程变量中的发起人编号查询部门，避免错误使用当前登录用户，由 @周洋洋 贡献 922c8b83 ，对应 IK8441
